# Ship Port Data Analysis – Power BI Dashboard

## Project Overview

This project presents an interactive **Power BI dashboard for analyzing global port efficiency and country-level performance**. It explores port efficiency indicators across different countries and regions, compares performance scores, and identifies the top- and bottom-performing countries.

The dashboard helps users understand global performance patterns through interactive charts, rankings, KPIs, maps, and filters.

## Dashboard Pages

The project contains four interactive dashboard pages:

### 1. Global Overview
- Displays the overall average port efficiency.
- Shows the highest and lowest scores.
- Presents the number of countries, regions, and years.
- Compares average port efficiency across regions.
- Displays countries by region using a map.
- Shows port efficiency trends over time.

### 2. Country Ranking
- Displays the top 20 performing countries.
- Identifies the bottom 20 performing countries.
- Compares country rankings and efficiency scores.
- Visualizes ranking versus performance score.
- Shows country ranking trends over time.

### 3. Performance Distribution
- Analyzes the distribution of port efficiency scores.
- Displays average efficiency, median score, and standard deviation.
- Classifies countries into performance levels: Excellent, Good, Average, and Poor.
- Shows the global performance trend.
- Compares performance scores across regions.

### 4. Top & Bottom Performers
- Identifies the first and last countries in the dataset.
- Displays the highest and lowest scores.
- Compares the top 10 and bottom 10 performing countries.
- Shows differences from the global average.
- Provides detailed country-level performance information.

## Tools and Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization.
- **Power Query** – Data preparation and transformation.
- **DAX (Data Analysis Expressions)** – Measures and calculations.
- **CSV / Dataset** – Source data analysis.

## Key Features

- Interactive dashboard with four pages.
- Country-wise and region-wise comparisons.
- Dynamic Year, Region, and Country filters.
- KPI cards for important performance indicators.
- Top and bottom country rankings.
- Global performance analysis.
- Interactive charts, tables, and map visualizations.

## Project Objective

The main objective of this project is to analyze global port efficiency and performance indicators using Power BI. It aims to make country-level comparisons easier, identify performance gaps, and present meaningful insights through interactive visualizations.

## Conclusion

This project demonstrates how Power BI can be used to transform structured data into an interactive analytical dashboard. The four dashboard pages provide different perspectives on global port efficiency, country rankings, regional performance, and top and bottom performers.
